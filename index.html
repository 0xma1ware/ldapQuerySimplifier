    04 Search context & commands

    Replace the example domain and server (a hostname or IP). PowerShell requires the ActiveDirectory module. Kerberos uses LDAPS with your existing ticket; simple bind uses LDAP and prompts for the password with -W / Get-Credential, so no secret is placed on the command line. Results page in batches of 1,000. Commands are generated locally; this tool never connects to AD.

    PowerView needs no RSAT and uses your current token (or -Credential). NetExec/windapsearch credentials are placeholders — -k/--kerberos uses a ticket, <password> marks the secret, and the domain is derived from the base DN. When the return attributes include nTSecurityDescriptor, the ldapsearch line adds the SD-flags control (owner+DACL) so a non-admin read is not blanked.

    Filter syntax & matching rules
    IntentSyntaxMeaning
    AND / OR / NOT(&(a=1)(b=2)) / (|(a=1)(b=2)) / (!(a=1))AND and OR require children. NOT requires exactly one.
    Equality / inequality(cn=Alice) / (!(cn=Alice))Negate an equality filter for not equal.
    Presence / absence(description=*) / (!(description=*))Whether an attribute has a value.
    Comparison(logonCount>=10) / (logonCount<=10) / (cn~=Alice)Bare > and < are invalid. Approximate matching depends on server support.
    Substrings(cn=Al*) / (cn=*ice) / (cn=*lic*)Starts with / ends with / contains. Escape a literal star as \2a.
    Bitwise AND1.2.840.113556.1.4.803All mask bits must be set.
    Bitwise OR1.2.840.113556.1.4.804At least one mask bit must be set.
    Recursive DN match1.2.840.113556.1.4.1941Follows DN links such as member or memberOf.
    Extensible match(userAccountControl:1.2.840.113556.1.4.803:=2)Optional :dn includes DN attributes. Other matching rules depend on the directory.
    Escape a literal filter value

    Filter escaping: * → \2a, ( → \28, ) → \29, backslash → \5c, NUL → \00. DN escaping is a separate layer: enter an already formed DN as a literal value.
